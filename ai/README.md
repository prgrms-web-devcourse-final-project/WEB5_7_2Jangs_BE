# AI 보조 개발 문서

이 폴더는 Docsa에서 AI를 어떻게 통제하고 검증하는지 설명하는 문서를 모은다.

| 문서 | 역할 |
| --- | --- |
| [`ai-assisted-development-workflow.md`](ai-assisted-development-workflow.md) | AI 활용 흐름을 기록하고 개선하는 워크플로우 정리본 |
| [`ai-usage-guide.html`](ai-usage-guide.html) | AI 활용 흐름과 판단 기준을 설명하는 사람용 HTML 문서 |
| [`logging-hook-reproducibility-plan.md`](logging-hook-reproducibility-plan.md) | Logging Hook과 검증 재현성 구축 계획 |

저장소 루트의 `AGENTS.md`는 AI가 따라야 할 실행 규칙이다. `ai-assisted-development-workflow.md`는 AI 활용 흐름을 기록하고 개선하는 정리본이고, HTML 문서는 사람이 작업 방식과 판단 근거를 이해하기 위한 설명 문서이다.
