## 🔨 기술 스택

### Backend
- **언어**:   `Java 21`  
- **프레임워크**:   `Spring Boot 3.5.3`, `Spring MVC`, `Spring Security`, `Spring Data JPA`  
- **데이터베이스**:   `MySQL`, `MongoDB`  
- **캐시**:   `Caffeine Cache`  
- **서버**:   `AWS EC2`, `AWS RDS`, `NginX`
- **모니터링**:   `Prometheus`, `Grafana`
- **테스트 도구**:   `JUnit5`, `Mockito`  
- **API 테스트**:   `Postman`
### Collaboration & Tools
- **협업 도구**: `Slack`, `Notion`  
- **IDE**: `IntelliJ`  
- **버전 관리**: `Git`, `GitHub Projects`
