공용 Gateway 운영 구조 정리

Docsa와 home-gateway의 Nginx·인증서 책임을 실제 운영 구조에 맞추고, 서버 레거시를 롤백 가능하게 정리한다.

책임 분리

공용 Gateway가 외부 80/443과 인증서를 소유한다. Docsa는 애플리케이션·모니터링과 스테이징 Nginx를 관리하며, 스테이징 Nginx는 Gateway 인증서를 읽는다.

작업 순서

  1. Docsa Compose의 운영 Nginx·Certbot 책임을 제거하고 계약 테스트로 고정한다.
  2. home-gateway의 갱신 스크립트·cron·운영 문서를 정리한다.
  3. 서버 파일과 crontab을 날짜별로 백업한 뒤 HTTPS와 health를 검증하며 전환한다.

검증과 범위

Compose 렌더링, 셸 문법, 인증서 갱신 dry-run, Gateway·운영·스테이징 HTTPS 및 health를 확인한다. 전체 백엔드 테스트는 이 인프라 작업의 범위가 아니다.

위험

서버 변경 전 롤백 백업을 반드시 만든다. 기능 브랜치의 사용자 변경은 건드리지 않는다.

세부 파일과 전환 순서는 Markdown 구현 계획에서 확인한다.
