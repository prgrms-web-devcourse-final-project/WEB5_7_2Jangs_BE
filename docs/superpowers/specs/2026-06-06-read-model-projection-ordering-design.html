Read Model Projection 순서 안정화

범용 Domain Event Outbox는 유지하면서 첫 consumer인 문서 목록 projector의 중복·역순 처리 정책을 보완한다.

선택한 설계

  • Wakeup은 정확성 보장이 아닌 relay를 깨우는 지연 감소 신호로 제한한다.
  • Relay는 OPEN 이벤트를 createdAt ASC, id ASC 순으로 처리한다.
  • title·activity·thumbnail·삭제에 각각 projection marker를 둔다.
  • 삭제는 terminal event로 처리하고 updatedAt은 과거로 되돌리지 않는다.

제외한 범위

message broker, CDC, aggregate version, consumer checkpoint, 문서 목록 API 계약 변경, 기존 백필 삭제는 이번 범위에 포함하지 않는다.

검증 기준

같은 필드의 오래된 이벤트는 막고, 다른 필드의 누락 이벤트는 필요한 범위에서 허용한다. 삭제 이후 이벤트는 문서를 되살리지 않아야 하며, wakeup 인자로 오래된 이벤트를 받아도 relay는 생성 이벤트부터 처리해야 한다.

한계

다중 relay 인스턴스에서 완전한 per-aggregate ordering은 보장하지 않는다. 현재 구조에서 데이터 손상을 줄이는 방어 정책이며, 더 큰 확장은 별도 설계가 필요하다.
