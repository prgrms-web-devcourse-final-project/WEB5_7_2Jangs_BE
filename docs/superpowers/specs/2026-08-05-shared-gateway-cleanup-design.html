공용 Gateway 운영 구조 정리

외부 트래픽과 인증서 갱신을 home-gateway로 일원화하고, Docsa 스테이징 Nginx는 같은 인증서를 읽도록 정리한다.

운영 책임

Docsa는 애플리케이션·DB·모니터링과 스테이징 Nginx를, home-gateway는 외부 80/443·운영 Docsa·DevChat 라우팅과 모든 인증서 갱신을 관리한다.

인증서 흐름

HTTP-01 요청은 Gateway의 /srv/gateway/certbot/www가 처리한다. 인증서는 /srv/gateway/certbot/etc에만 갱신하고 gateway-nginx와 docsa-nginx-stg가 함께 읽는다. 갱신 뒤 두 컨테이너를 reload한다.

전환과 롤백

Compose, Nginx 설정, 인증서와 사용자 crontab을 날짜별 롤백 디렉터리에 보관한다. root 갱신 작업 설치를 확인한 뒤 일반 사용자 crontab을 제거한다.

검증 범위

Compose 렌더링, 셸 문법, 갱신 dry-run, Gateway·Docsa 운영·스테이징 health와 HTTPS 인증서를 확인한다. 전체 애플리케이션 테스트는 실행하지 않는다.
