PERFORMANCE COMPARISON

commit 삭제 비교

단일 사용자, 30회 실행을 3회 반복한 outbox 병합 전후 집계다.

결과

지표병합 전병합 후변화
삭제 p5084.37 ms105.36 ms+24.88%
삭제 p952,921.49 ms163.42 ms−94.41%
삭제 평균620.82 ms116.23 ms−81.28%

검산과 한계

변화율은 (병합 후 − 병합 전) / 병합 전 × 100이다. 비민감 집계 근거로 재계산할 수 있다.

p50은 악화됐으므로 p95·평균 개선과 함께 해석한다.

전체 지표는 Markdown 보고서를 확인한다.
